RiccoDo 개인정보처리방침

시행일: 2026년 11월 19일

RiccoDo(이하 ‘앱’)는 할 일과 미리알림을 관리하는 Android 앱입니다. 회원가입, 광고, 사용 통계 수집 도구가 없으며 인터넷 권한을 사용하지 않습니다. 개발자는 사용자의 개인정보를 수집하거나 서버로 전송하지 않습니다.

1. 기기에 저장되는 정보

정보저장 위치와 보관
할 일의 제목·메모·날짜·알림 시각·반복·색 태그·고정·그룹, 완료 기록사용자 기기의 앱 전용 저장 공간
테마·글자 크기·소리·진동·정렬 및 위젯 설정사용자 기기의 앱 전용 저장 공간
휴지통의 할 일30일 보관 후 앱 실행 시 정리. 사용자가 그 전에 되살리거나 영구 삭제할 수 있습니다.
내부 자동 백업앱 실행 시 하루 한 번 저장하며 최근 7개 보관. 복원 직전 백업은 별도로 최근 3개 보관합니다.

앱은 위 정보를 개발자나 제3자의 서버로 전송하지 않습니다.

2. 사용자가 내보내는 백업 파일

사용자가 ‘백업 파일 내보내기’를 선택하면 시스템 파일 선택기로 직접 고른 위치에 할 일·그룹·설정이 담긴 JSON 파일을 저장합니다. Download 폴더 같은 기기 저장소나 사용자가 연결한 클라우드 저장 위치를 선택할 수 있습니다. 클라우드 위치를 고른 경우 파일의 전송·보관은 해당 저장 서비스가 처리하며 그 서비스의 정책이 적용됩니다. 개발자는 이 파일에 접근하지 않습니다.

내보낸 백업에는 할 일 제목과 메모 등이 포함되므로 안전하게 보관하세요. 앱을 삭제해도 앱 밖에 내보낸 파일은 남을 수 있으며 사용자가 직접 삭제해야 합니다.

3. 미리알림과 권한

미리알림은 기기 안에서 예약하고 표시합니다. 알림에는 할 일 제목과 메모 일부가 표시될 수 있으므로 잠금화면 공개 범위는 Android 알림 설정에서 조절할 수 있습니다.

권한사용 목적
알림 (POST_NOTIFICATIONS)Android 13 이상에서 미리알림 표시
정확한 알람 (USE_EXACT_ALARM / SCHEDULE_EXACT_ALARM)정한 시각에 알림 예약. SCHEDULE_EXACT_ALARM 선언은 Android 12L 이하에 적용됩니다.
부팅 완료 수신 (RECEIVE_BOOT_COMPLETED)폰을 다시 켠 뒤 남은 알림 다시 예약
진동 (VIBRATE)완료 시 짧은 진동과 미리알림 진동

앱에는 인터넷 권한이 없습니다. 위젯도 기기 안의 할 일만 사용합니다.

4. 정보의 삭제와 복원

앱에서 할 일을 삭제하면 휴지통으로 이동하며, 영구 삭제하거나 보관 기간이 지난 뒤 정리할 수 있습니다. 앱을 삭제하거나 Android에서 앱 데이터를 지우면 앱 안의 할 일·설정·내부 자동 백업이 지워집니다. 폰을 바꾸거나 앱을 삭제하기 전에는 별도 백업 파일을 내보내세요.

백업 복원은 현재 데이터를 백업 내용으로 바꿉니다. 복원 직전 현재 데이터를 앱 안에 자동 백업합니다.

5. 아동의 개인정보

앱은 연령과 관계없이 개인정보를 수집하지 않으며 아동 대상 광고·추적 기능도 없습니다.

6. 변경 및 문의

방침이 변경되면 이 페이지에 게시합니다. 문의는 GitHub Issues에 남겨 주세요. 문의에 개인정보나 실제 할 일 내용을 포함하지 않도록 확인해 주세요.
